# Инструкции для проекта child-phone-cordova

Этот репозиторий содержит Cordova-приложение, которое ограничивает функциональность телефона для детей и работает в режиме киоска.

## Обязательные требования по workflow
В проекте обязательно должен быть файл workflow.md, в котором кратко описываются:
- все поставленные задачи, над которыми ведётся работа;
- проблемы и blockers, с которыми столкнулись по пути;
- способы, которыми эти проблемы были решены или планируется решить.
Каждая задача в workflow.md оформляется отдельным разделом с подзаголовками «Что нужно сделать», «Проблемы и блокеры» и «Решения проблем и план», добавляется в конец файла и обновляется по мере работы.
Перед началом работы нужно прочитать workflow.md, а при выполнении каждой новой задачи — обновлять его актуальной информацией.
Все новые задачи в workflow.md добавляются в конец, для сохранения хронологии.
Если в ходе работы меняется ТЗ и появляются новые требования/функции/возможности - их нужно описывать в README.

Перед изменениями в каталоге этого репозитория читайте и следуйте инструкциям этого файла.
