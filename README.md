# Child Phone Cordova

Мобильное приложение для детских телефонов, построенное на Apache Cordova. Цель — дать ребёнку доступ только к безопасному минимуму функций телефона и скрыть остальное за режимом киоска.

## Основные возможности
- **Режим киоска (Device Owner / COSU)**: блокирует доступ к другим приложениям и системным настройкам.
- **Минимально необходимый функционал внутри приложения**:
  - Проводник файлов/папок на устройстве.
  - Музыкальный и видеопроигрыватель.
  - Читалка электронных книг.
- **Запуск разрешённых сторонних приложений** из заранее утверждённого списка.
- **Административный выход**: по нажатию административной кнопки и вводу пароля взрослого временно отключает режим киоска и возвращает стандартный функционал телефона.
- **Автообновление через Syncthing**: приложение хранит данные в общей папке, проверяет файл `version` и при расхождении с версией в памяти браузера обновляется (перезагружает веб-приложение без кэша).

## Текущий статус
Репозиторий содержит каркас Cordova-приложения, который при запуске включает режим киоска и показывает единственную страницу с кнопкой «Выход», отключающей режим киоска. Реализация файлового менеджера, медиаплееров, читалки и списка разрешённых приложений планируется на следующих итерациях.

## Сборка и запуск
1. Установите Cordova: `npm install -g cordova`.
2. Установите платформу (пример для Android): `cordova platform add android`.
3. Соберите приложение: `cordova build android`.
4. Установите в эмулятор или на устройство: `cordova run android`.

### Зависимость от плагина киоска
Для активации/деактивации киоска требуется совместимый плагин (например, `cordova-plugin-kiosk`). В `www/js/app.js` используются вызовы `navigator.kiosk.lock()` и `navigator.kiosk.unlock()`; убедитесь, что плагин предоставляет такие методы или адаптируйте код под выбранный плагин.

## Автообновление через Syncthing
- Все данные приложения синхронизируются через общую папку Syncthing.
- Во время работы приложение сверяет файл `version` в синхронизируемой папке с версией, сохранённой в памяти браузера (JavaScript-переменная). При несовпадении версия обновляется и страница перезагружается без кэша.
